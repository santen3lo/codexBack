# LLM Compare — Параллельное сравнение ответов нейросетей

Веб-сервис для одновременной отправки запроса нескольким LLM-моделям и сопоставления их ответов в едином удобном интерфейсе.

Сервис позволяет:
- **Узнать, что модели знают о бренде или продукте** (например, о команде CodeX и редакторе Editor.js);
- **Выбрать оптимальную модель для своих задач** по скорости, качеству и стоимости;
- **Перепроверить факты** при расхождении ответов разных сетей.

Интерфейс строго следует [макету Figma](https://www.figma.com/design/OYERN0YVPLt1JmYbF9d3te/LOCAL-DRAFT?node-id=2609-2229&t=wuYqr29pmdvTX5XS-1), адаптивен для мобильных устройств (колонки автоматически трансформируются во вкладки) и реализован **без использования готовых UI-библиотек компонентов** (все компоненты сверстаны вручную с помощью утилитарного Tailwind CSS).

## 🚀 Выполненные требования

### Минимальные требования:
- [x] **Клиент-серверная архитектура**: запросы к моделям отправляются исключительно сервером.
- [x] **Поддержка AI Proxy ([slaveeks/ai-proxy](https://github.com/slaveeks/ai-proxy))**: работа по протоколу потоковой выдачи NDJSON (`/stream`), синхронной (`/generate`), а также OpenAI-совместимому API.
- [x] **Динамический список моделей**: бэкенд отдает список доступных моделей (`GET /api/models`).
- [x] **Выбор от 2 до 4 моделей**: добавление через колонку «+ Добавить модель», удаление по крестику в шапке (с блокировкой удаления при 2 моделях).
- [x] **Параллельные асинхронные запросы**: сервер отправляет промпт во все выбранные модели одновременно (`asyncio.gather` / параллельные streaming tasks).
- [x] **Колонки ответов и закрепленная шапка**: sticky header с названием модели, провайдером и кнопкой удаления; время ответа под каждым блоком.
- [x] **Рендеринг Markdown**: заголовки, списки, таблицы с границами, блоки кода с подсветкой синтаксиса и кнопкой «Copy».
- [x] **Сворачиваемый блок мыслей (Thinking)**: `⏱ Думала 4 секунды ∨` для reasoning-моделей.
- [x] **Изоляция ошибок и таймауты (60 сек)**: сбой или таймаут одной модели не ломает другие колонки; выводится понятная карточка ошибки и кнопка **«Повторить»** только для этой модели.
- [x] **Мобильная адаптивность**: на экранах `< 768px` колонки плавно превращаются в горизонтальный переключатель вкладок (tabs).
- [x] **Безопасность**: токен доступа хранится в `.env`, не попадает в git и в клиентский бандл.
- [x] **Шеринг конфигурации**: кнопка «Скопировать ссылку» сохраняет набор выбранных моделей в URL query.

### Реализованные расширенные требования:
- [x] **Метрики (Backend + Frontend)**:
  - **TTFT (Time to First Token)**: точное время до получения первого токена ответа;
  - **Общее время генерации** (в секундах);
  - **Подсчет токенов**: количество входных (prompt) и выходных (completion) токенов;
  - **Расчет стоимости запроса**: вычисление стоимости в USD на основе актуальных тарифов моделей;
  - **Автоматическая подсветка**:
    - ⚡ **«Быстрее всех»** (зеленый бейдж для модели с минимальным временем);
    - 🏷️ **«Дешевле всех»** (бейдж для наиболее экономичной модели).

## 🛠 Стек технологий

- **Backend:**
  - Python 3.11+
  - **FastAPI** — высокопроизводительный асинхронный веб-фреймворк
  - **Uvicorn** — ASGI-сервер
  - **HTTPX** — асинхронный HTTP-клиент со стримингом и независимыми таймаутами
  - **Tiktoken** — точный подсчет токенов
  - **Pydantic v2** — валидация схем и строгая типизация
  - **Pytest** — автоматизированное тестирование API и расчетов метрик

- **Frontend:**
  - **React 18** + **TypeScript** + **Vite**
  - **Tailwind CSS** — кастомная дизайн-система в темной теме по макету (без готовых UI-библиотек)
  - **React-Markdown** + **Remark-GFM** — поддержка таблиц, списков и форматирования Markdown
  - **PrismJS** — подсветка синтаксиса кода с кнопкой «Copy»
  - **Lucide React** — минималистичные иконки

## ⚙️ Настройка окружения (`.env`)

Создайте файл `.env` в корне проекта (или скопируйте `.env.example`):

```bash
cp .env.example .env
```

Пример содержимого `.env`:

```ini
# Токен доступа к CodeX AI Proxy
AI_PROXY_TOKEN=your_token_here

# Базовый URL прокси
AI_PROXY_BASE_URL=http://llm.codex.so

# Таймаут на ответ одной модели (в секундах)
DEFAULT_TIMEOUT_SECONDS=60.0

# Порт бэкенда
PORT=8000
HOST=0.0.0.0
```

> **Примечание:** Если токен не указан или сервис AI-прокси временно недоступен, бэкенд автоматически запускает режим реалистичной эмуляции стриминга (демо-режим с расчетом метрик, кода и таблиц), что позволяет протестировать интерфейс без расхода лимитов токена.

## 📦 Быстрый запуск

### Вариант 1: Через Docker (рекомендуется)

Сервис собирается в единый оптимизированный контейнер:

```bash
docker compose up --build
```

Приложение будет доступно по адресу: **`http://localhost:8000`**

---

### Вариант 2: Локальный запуск (Manual)

#### 1. Запуск бэкенда:
```bash
cd backend
python3 -m venv venv
source venv/bin/activate       # На Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

#### 2. Запуск фронтенда (в отдельном терминале):
```bash
cd frontend
npm install
npm run dev
```

Откройте в браузере: **`http://localhost:5173`** (запросы к `/api` автоматически проксируются на бэкенд `http://localhost:8000`).

---

## 🧪 Запуск тестов

Для запуска модульных и интеграционных тестов бэкенда:

```bash
cd backend
pytest tests/
```

Проверяются:
- Эндпоинты списка моделей и схема метаданных;
- Валидация ограничения количества моделей (2–4);
- Синхронное и потоковое выполнение параллельных запросов;
- Корректность замера TTFT, общего времени и расчета стоимости;
- Логика определения самой быстрой и самой дешевой модели.
